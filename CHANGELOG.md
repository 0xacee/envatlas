# Changelog

All notable changes to EnvAtlas are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-02

### Added

- Value-blind discovery of dotenv catalogs and static references in
  JavaScript, TypeScript, Python, shell, YAML/Compose, and Dockerfiles.
- Deterministic text and JSON reports with stable findings and exit codes.
- SARIF 2.1.0 output for native code-scanning annotations.
- Explicit glob policy, explain mode, and strict CI enforcement.

[0.1.0]: https://github.com/0xacee/envatlas/releases/tag/v0.1.0
